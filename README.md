# Bill-Splitting

SplitEat — an Expo (React Native) app that splits restaurant bills fairly by what each person ordered.

## Features

- Manual item entry and optional receipt photo (reference only, no OCR)
- People, groups, item assignment, tax / service / delivery
- Bill history, WhatsApp share, English + Arabic (LTR/RTL), light/dark theme

## Get started

```bash
npm install
npm run start
```

Then open with Expo Go, or press `a` / `i` / `w` for Android, iOS, or web.
